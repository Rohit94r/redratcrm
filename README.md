# Selvar CRM — Commercial Solar Revenue Desk

Exact, pixel-perfect CRM replica with full animations, drag-and-drop pipelines, AI Copilot, forecast runway, interactive charts, calendar, contacts, reports, team quotas, lead scoring, and light/dark theme support.

## 🚀 Quick Start

The dev server is currently running on **`http://localhost:3000`**.

To run it anytime:

```bash
# Install dependencies (already installed)
npm install

# Start the dev server
npm run dev
# or
npm start
```

Open [http://localhost:3000/#/overview](http://localhost:3000/#/overview) in your browser.

## 🌟 Included Screens & Capabilities

1. **Overview (`#/overview`)**:
   - Closed-won metrics & quota runway progress
   - Copilot recommendations & deal risk signals
   - Win rate, average deal size, sales cycle, and pipeline coverage cards
   - Weekly bookings chart & deal stage distribution
   - Today's agenda & scheduled calls
   - Deals needing action flag tracker
   - Team quota leaderboard race

2. **Pipeline (`#/pipeline`)**:
   - Drag-and-drop Kanban board for deal stages (Prospect, Site survey, Proposal, Negotiation, Won, Lost)
   - Deal quick filters and search
   - Deal inspector modal with history, stage moving, and notes

3. **Leads (`#/leads`)**:
   - Lead scoring model with interactive weight adjustments
   - Lead qualification matrix and conversion actions

4. **Copilot (`#/copilot`)**:
   - AI deal insights and risk flagging
   - Automated response drafting and customer nudges

5. **Calendar (`#/calendar`)**:
   - Interactive scheduling and pipeline meetings

6. **Contacts (`#/contacts`)**:
   - Company accounts, decision-makers, and solar stakeholder directory

7. **Reports (`#/reports`)**:
   - Revenue analytics, win/loss breakdowns, and cycle timelines

8. **Team (`#/team`)**:
   - Rep quotas, target progress, and team attainment

9. **Settings & Shortcuts (`#/settings`)**:
   - Light / Dark mode toggle
   - Collapsible sidebar rail
   - Global search modal via `Cmd+K` or `/`
   - Keyboard navigation (`g` then `o`/`p`/`l`/`a`/`c`/`r`/`t`/`s`)
